This website was created for my ICT 280 Final Project. It represents a client site from a given client portfolio. The site has 5 pages including home, about, products, resources, and contacts. The technologies include HTML, CSS, JavaScript, Accessibility, and Mobile Design. You can view the project by visiting: 
https://jennifer-rogers.github.io/web-project/final/index.html. The final folder contains the complete project. 

Instructions for Setup and Running the Project
I. View the Live Website
The project is hosted using GitHub Pages.
Open the final project at:
https://jennifer-rogers.github.io/web-project/final/index.html

II. Run the Project Locally (Optional)
If you want to run the project on your own computer:

Download or clone the repository:

Code
git clone https://github.com/jennifer-rogers/web-project
Open the final folder.

Open index.html in any browser (Chrome, Edge, Firefox, Safari).

III. Navigate the Website
Use the navigation bar to access all five pages:

Home

About

Products

Resources

Contacts

IV. Test Accessibility
The site includes:

Alt text for images

Proper heading structure

Form labels

High‑contrast mode

Keyboard‑friendly navigation

You can test accessibility using the WAVE Evaluation Tool.

V. Test Mobile Responsiveness
Open Developer Tools (F12)

Click the Device Mode icon (phone/tablet)

Select a device (iPhone, Pixel, iPad) to preview the responsive layout

VI. JavaScript Functionality
The Products page includes a JavaScript category filter.
Additional JavaScript enhances user interaction across the site.

Technologies Used
HTML5 – Structure and content

CSS3 – Styling, layout, and responsive design

JavaScript – Interactive features (category filter, UI enhancements)

Accessibility Tools – WAVE, alt text, labels, contrast

GitHub Pages – Hosting the final project
